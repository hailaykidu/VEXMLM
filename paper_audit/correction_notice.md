# Correction notice — draft

Paper: *Expanding the Lexicon of Ge'ez Based African Languages: A Comparative Study of Amharic
and Tigrinya* (LM4UC Workshop, IJCAI 2026). Corrected version titled *Vocabulary Expansion for
Low-Resource African Languages: A Case Study in Amharic and Tigrinya*.

Status: **draft.** All author decisions recorded (data statement: Option A; release tag `v1.1-correction`).

Evidence base: repository `github.com/hailaykidu/VEXMLM`, commit `1e56e55`. "Corrected" values are
generated by `scripts/make_paper_artifacts.py` from the files named in the Source column.
Published values are quoted from the published text; bars whose value the text does not state are described, not estimated.

## Summary of the correction

1. The published downstream and tokenizer values for Glot500 (Table 2, Figure 1, Table 4) could not
   be traced to any experimental output. Glot500 is removed from the downstream comparison; its
   tokenizer statistics are replaced by a measured run.
2. Tables 2 and 3 reported languages for which no evaluation exists. They are replaced by
   measurements for Amharic and Tigrinya.
3. Corrected downstream results show that VEXMLM does not outperform XLM-R on every task: NER
   improves modestly, QA is below XLM-R, and sentiment is comparable.
4. The corrected ablation shows that vocabulary expansion alone lowers accuracy; continued
   pretraining is required to exceed the baseline.
5. Several method details (precision, trainable parameters during fine-tuning, token selection,
   pretraining data description) are corrected to match the released code and model.

30,000 added pieces, the initialization formula (Eq. 2), the MLM probability 0.15, learning rates,
batch size 32, maximum length 256, weight decay 0.01, gradient clipping 1.0 and AdamW settings
match the released code and run records.
